# Tourism Web Design Project

A PHP-based tourism website built as part of an undergraduate web design course — features destination listings, travel packages, and a hotel/tour booking form.

## Pages
| File | Description |
|---|---|
| `index.php` | Home page with featured destinations |
| `package.php` | Travel packages listing |
| `book.php` / `book_form.php` | Booking interface and form |
| `About.php` | About page |
| `home.php` | Alternate home view |
| `css/style.css` | Stylesheet |
| `js/script.js` | Client-side scripts |

## Tech Stack
PHP · HTML · CSS · JavaScript
